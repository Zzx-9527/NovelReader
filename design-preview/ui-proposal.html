宣纸与朱印

现在这版的底子是好的（AppTheme.ets 里的令牌纪律、封面的书脊、三个 Tab 的通栏发丝线都很扎实）， 问题出在性格上：底色 #FAFAFA 是冷灰、正文 #1F1F1F 是纯灰黑、 主题色 #35597F 是冷钢蓝 —— 三样加起来的观感是「系统中立」，而不是一个读书的地方。 这一稿把配色整体挪到暖宣纸 + 墨 + 一点朱砂，并让所有标题落到衬线上。 暗色模式是同一套「纸与墨」换成暖黑 + 暖白（第 08 / 09 台），不是简单反转。 下面每台手机下方都注明了具体改了什么、对应哪个文件； 页首可以点选封面方案 A / B / C。

改了什么：
· 封面重做：左侧朱砂书脊 + 内圈双线框 + 居中书名首字 + 底部进度发丝。原来的封面是「灰底 + 一个居中大字」，一屏九格读起来是九个灰块；双线框给了它「这是一本书的封面」的形。左侧圆角小、右侧圆角大，模拟书脊的厚度（BookCover.ets）。
· 继续阅读：从「一张卡片 + 一个按钮」改成一条书签 —— 左侧一道朱色标线、上方 续读 眉标、书名落衬线。整块不再是一张泛白的卡。
· 操作入口：三个描边胶囊（排列/排序/＋分组）收成两个朱色文字动作，「导入」不再抢视觉（BookShelfPage.buildHeader）。
· 标题落衬线：书架、书名、分组名全部走衬线 + 字距。这是「书卷气」在真机上唯一确定能拿到的来源（AppFont.titleFamily() 已经预留了这个口子）。
· 分组封面：改成「册」字 + 本数，用中性灰而非主题色，与书区分得开又不抢戏。

第十二章 · 雪落无声

雪是从后半夜开始下的。起初只是零星几点，落在窗纸上，像谁在外面轻轻叩门。他醒着，却没有起身。

灯已经灭了很久，屋里只剩下炭盆里那一点将熄未熄的红。他数着自己的呼吸，一，二，三，一直数到三百，雪声才渐渐密起来。

这样的夜里，什么都不必想。他记得小时候母亲说过，落雪的时候，天与地之间隔着一层棉，人说的话传不远，所以雪夜里可以放心地说真话。

他于是很轻地说了一个名字。雪把它接住了，没有还回来。

天亮时，院子里已经积了三寸。他推开门，看见廊下那株老梅，枝上压着一层白，却还是有几朵探出来，红得有些莽撞。
