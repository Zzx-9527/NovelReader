静读 · 界面重构预览 — 主题色一个值都没动

方向：「纸与线」。不换配色、不换主题、不换信息架构，只补三样东西 —— 发丝线（层级与分区）、书脊与衬线首字（让封面真的像书）、 等宽数字与状态（数字不跳、控件有焦点态）。所有颜色仍取自 base|dark/element/color.json 的既有令牌，零新增。

实施记录 · 已按第 07 节「改动清单」1–4 全部落到 ArkTS

下面六条是落地时与这份预览不同的地方。前两条是实测/量测之后必须改的，后四条是零风险的等价实现。

  1. 衬线字体：最终决定不做，理由是体积不划算。 查了本机 SDK 的声明文件，两条说明连起来是死路： text.d.ts 写 "Default font: 'HarmonyOS Sans'; The 'HarmonyOS Sans' font and registered custom fonts are supported"， 而 UIContext.d.ts 写 getSystemFontList() "takes effect only on 2-in-1 devices"。 也就是说：手机上任何"未注册"的中文衬线都不会生效 —— 唯一的路是用 registerFont 往包里塞一个字体文件。
    而中文衬线（思源宋体一类）动辄 10~20 MB，本项目的标题只用到几十个不同的字。 为了这几十个字背 20 MB 字库，与"完全离线、轻量、零图片依赖"的定位不相称，所以刻意不引入字体资源。 落地方式：common/theme/AppFont.ets 只保留两级 —— 系统自带的衬线（仅 2-in-1 可能命中） > 系统无衬线，并保留一次零成本的同步探测（在 loadContent 之前，避免启动页品牌字闪一下）。 "书卷气"由字距 + 字重 + 题花线承担 —— 这三样与字体、设备、系统版本全部无关，是确定性收益。
  2. 书架头部改成两行。 原预览把「书架 + 计数」与四个操作挤在同一行。量了一下：三个胶囊约 50/50/62vp、「导入」约 56vp、 四个 8vp 间距共 32vp，合计 250vp；整行可用 328vp —— 留给标题的只有 78vp， 而「书架」占 40vp、计数需要约 76vp，零余量，任何字体差异都会把计数截成省略号。 落地方式：标题与「导入」一行、三个胶囊单独一行。多花 30vp 高度，换来标题不再被压缩。
  3. 分组封面去掉 1vp 描边。 给 3:4 的格子加 border 会让它比同一行的书籍格高 2vp；网格行高取最大值， 于是整行错开 2vp。改用底色分段表达结构：封面底边留 18vp 的标签板（coverBg 底 + 计数文字）， 与书籍封面（整片纸 + accent 书脊）一眼可分，且不需要新增任何颜色。
  4. 阅读页题花线叠在标题的下内边距里，不占新的一行。 headingHeight() 是按"行高 + 上下内边距"算给分页服务的（首页要给标题让位）。 若题花线真的占一行，就必须同步改那个函数；漏改的后果是首页多算一行、最后一行正文被裁掉，而且不报错。 所以题花线用 Stack 叠在既有的 12vp 下内边距之内 —— 总高一个 vp 都不变，分页算术完全不受影响。 装饰只允许改宽度方向，不允许改高度方向。
  5. 列表两种形态共用同一份底色。 书架页把整列收成一块卡片后，行本身仍保留自己的 bgCard 底 —— 因为外层容器同色且带裁切，两层同色不透明叠加在像素上完全一致。 这样避免了写出 Color | Resource 这种本项目从未出现过的混合联合类型。
  6. 柱状图"今天"的圆点挖在柱子内部。 若把圆点做成柱子上方的兄弟节点，带 margin 时外层高度会变成 max(柱高, 圆点+边距) —— 矮柱子被顶高、柱底离开基线，看起来像数据不对。 改成"柱子本身是个容器、圆点画在柱顶内侧"，高度恒等于柱高。

01 · 书架 · 网格

封面是收益最大的一处。原版是「灰底 + 书名首字」的纯色块，一屏九格全是同一块灰； 新版给每本书一条 accent 书脊（3vp，55% 不透明度 —— 仍属小面积点缀， 没有违反「大色块一律中性」的既有纪律），首字换衬线并加大，下方一条 18vp 发丝线收住重心， 进度从右下角黑角标改为封面底边的 2vp 进度发丝。配色零改动，观感从「色块」变成「书」。

07 · 改动清单

下面每一条都可以单独否决 —— 说「第 3 条不要」我就跳过它。执行顺序按对观感的影响排序。

零改动 红线
  • color.json 一个值都不改：base 17 个 + dark 17 个令牌原样保留，不新增令牌。
  • 四套阅读底色不动：浅色 #FFFFFF / 羊皮纸 #F5EDE0 / 护眼 #CCE8CF / 夜间 #111111。
  • 信息架构不动：三个 Tab、页面层级、目录独立页、书签入口、覆盖式菜单栏，全部保持。
  • AppTheme 数值不动：字号 20/16/14/12/13、圆角 12/8/14、间距 8/12/16、栏高 52/48/30 保持。
  • 零图片依赖不变：仍然只用 resources/base/media 下已有 SVG + 字形，不引入 PNG/字体文件。
一 · 封面成为「书」 影响最大
  • 书脊：封面左侧 3vp accent，不透明度 0.55。一屏 9 格合计约 27vp² 的着色面积 —— 仍是「小面积点缀」，没有违反 AppColor.accent 注释里那条纪律。
  • 衬线首字：22 → 27，字体族从系统无衬线换成衬线（设置项可关，见风险）。
  • 题花线：首字下方 18×1vp 发丝线，用 cover_text 45% 不透明度收重心。
  • 进度改到底边：删掉右下角黑角标（mask + onScrim），换成封面底边 2vp 进度发丝；百分比文字移到右上角，9 号 cover_text，无底色。
  • 分组封面区分：2×2 结构保留，加 1px divider 内描边；「3 本」角标同样去底色，改为左下角安静文字。
二 · 层级靠线，不靠色块
  • 书架头部：「书架」下加计数副标题（7 本 · 2 个分组，12 号 text_hint）；头部下方通栏 divider 发丝线，且向右出血到屏幕边（左 16vp 起）。
  • 操作区收成胶囊：列表 / 排序 / ＋分组 从裸文字变成 30 高、1px divider 描边、15 圆角的胶囊；「导入」仍为中性实心。
  • 列表收成一块：每本一张卡 → 一整块 bg_card + 行间发丝线，分隔线左缩进到 72vp（封面 48 + 间距 12 + 内边距 12），与文字列对齐。
  • 底部导航加顶线，选中项在图标上方加一条 18×2vp accent 短横（在已有 48vp 高度余量内，不加高）。
  • 阅读页加三条发丝线：顶栏下沿、菜单两行之间、常驻底栏上沿（后者从 100% theme.secondary 降到 30%，原来那条太重，像框线）。
  • 章节题花：章节标题下 24×1vp theme.secondary 55% 短线 —— 全文只此一处装饰。
三 · 数字与状态
  • 等宽数字：页码、百分比、章数、统计数值全部走 tabular figures。翻页时 5/16 → 6/16 不再左右抖动。
  • 统计页去模板化：4 张同尺寸卡片 → 一块账页 4 行（左标签 / 右数值 / 行间发丝线）。柱宽 18→14、圆角 4→3、补基线、今天加 accent 圆点。
  • 进度条升级：继续阅读卡与列表项的进度从 4vp 实心块换成 2vp 发丝轨道 + accent 填充，继续阅读卡末端加 6vp 圆点。
  • 输入框补状态：1px divider 描边 → 聚焦 1.5px accent 描边；caretColor 设为 accent（原来是系统默认蓝，与主题不搭）。
  • 箭头改手绘：我的页 › 文本字形换成 1.5px 描边的 SVG 折线，粗细位置不再随字体漂移。
  • 危险项上色：我的页「清空所有数据」用 danger（原来与普通项同色，只有弹窗里才提示危险）。
四 · 空 / 加载 / 启动
  • 空状态加标记：92×92 纯几何线稿（三张叠放纸页 + accent 书签带），三段不透明度做纵深。不使用插画、不使用 emoji，全部是圆角矩形与直线 —— 符合「SVG 画几何，不画图像」。
  • 骨架屏替代转圈：首屏加载时按真实版面铺 6 个封面骨架 + 头部骨架，1.5s 缓动呼吸（cover_bg 填充，无新增色）。带文字的加载态（重新解析、正在打开）仍保留转圈。
  • 错误态换标记：✗ 字形（字体不同大小不一）换成 30vp 手绘圆圈 + 感叹号，danger 色；文案补上「已导入的文件不会丢失」。
  • 启动页落款：wordmark 字距 0.14em + 下方 30×2vp accent 短线。
风险与取舍 需要你拍板的两点
  • 衬线字体可用性：HarmonyOS 不一定预装中文字体衬线族。方案：fontFamily 走 Source Han Serif SC / Noto Serif SC / HarmonyOS Sans SC 顺序尝试，取不到就自动回退无衬线，不报错、不影响分页（分页测量的 measureTextSize 与渲染共用同一个 resolveFontFamily()，不会出现「量的时候用 A、画的时候用 B」）。你可以先用上面「标题字」开关看两种观感再定。
  • 等宽数字：走 .fontFeature('"tnum" 1')，设备字体若不支持该特性则自动忽略，无副作用。
  • 骨架屏的代价：书架首次加载会多一次排版，但省掉「转圈 → 内容」的跳变。若你觉得闪，可以退回转圈，只保留其余改动。
  • 不加动效：除已有的 Tab 图标 120ms 变色、菜单栏 180ms 滑入外，本次不新增任何动效 —— 产品界面里动效只在传达状态时才用。
